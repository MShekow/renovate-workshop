# Driver instructions

As a driver, you don't need to think much! You are **not** going to read the task-specific instructions of `README-mob-navigator.md`. Instead, the navigators tell you exactly what to do.

A driver only executes these kinds of activities:
1. Typing code
2. Committing and pushing changes to GitHub
3. Navigating on github.com in the repo copy where Renovate creates the PRs
3. Opening links, only when explicitly instructed by the participants (the links are provided below in section `Task-specific links`)

You can do all these activities via the browser-based remote desktop. However, if task 1 (typing code) causes problems because of incompatible keyboard layouts (macOS), you can also use your **VSCode Live Share** session to change code.

## Becoming a driver

Once it is your turn to be the driver, you will drive the session for only **10-15 minutes**. The workshop instructor will coordinate the driver switch.

To become a driver, you need to open a _VNC remote desktop_ connection (browser-based, no need to install a client):
- Open the `https://<something>.app.github.dev/vnc.html` link shown in the _Google Doc_ that contains all workshop material links
- Click "Connect" button, then use "workshop" for the password
- The Google Doc also explains how you should customize the VNC _scaling_ settings
- In the VNC session, you stay in the _Firefox_ browser at all times. The instructor already prepared a few browser tabs, e.g.,
  - a logged-in GitHub account, already having imported a copy this repo into the GitHub personal account
  - This `README-mob-driver.md` file
  - A VS Code Live Share session which grants you access to a writeable terminal that you will use for `git` commands
